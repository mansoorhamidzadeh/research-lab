# Datasets

Sample inputs and generated outputs for the evaluation work in [../evaluation/](../evaluation/).

- `txt_example.txt`, `docx_example.docx`, `pdf_example.pdf` — small source documents used to exercise document loaders and synthetic golden generation.
- `20250727_103234.json`, `20250803_102343.json` — synthetic goldens produced by the DeepEval synthesizer notebooks.

The notebooks reference these as `../../Datasets/<file>`, relative to `evaluation/deepeval/`.
